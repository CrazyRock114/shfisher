> 调研时间：2026-10-02 · 18 次搜索 + 6 次页面核实。无法核实处标注"待验证"。

## 一、影响钓鱼效果的水文指标

**水位（涨落）**：鱼对水位变化极其敏感。涨水淹没新滩带来食物，鱼靠边觅食；落水太快鱼退回深水、口差；稳定水位最好钓。上海河网属平原感潮水系，水位涨落主要由潮汐驱动而非降雨，因此"看水位"在上海核心是"**看潮**"。

**流速**：流水带来溶氧和食物，微流好钓，急流难钓（走漂、鱼顶流耗力）。上海钓鱼的黄金窗口是"**转流期**"——急流转缓流前后 1–2 小时，饵料鱼被潮流搬运、掠食鱼最活跃；平潮停潮时段水静、溶氧低、鱼最不咬钩。

**水温**（各目标鱼开口区间，据[钓鱼人](https://m.diaoyur.com/a/2021/62268.html)、[知乎](https://zhuanlan.zhihu.com/p/619556642)等钓技资料汇总）：

| 鱼种 | 开口水温 | 最旺区间 | 备注 |
| --- | --- | --- | --- |
| 鲫鱼 | 3–4℃ 微口 | 15–25℃（20℃ 摄食量最大） | 耐寒性最强，超 30℃ 基本停口 |
| 鲤鱼 | 8℃ 试探摄食 | 12–15℃ 稳定开口 | 超 28℃ 口差、转清晨傍晚 |
| 草鱼 | 约 15℃ 起步 | 20–32℃（27–30℃ 最活跃） | 喜高温 |
| 翘嘴 | 10–33℃ | 15–33℃ 狂口 | 可钓窗口最宽 |

水温滞后气温约半天，晴天可按"白天最高气温 ≈ 次日水温"估算。

**溶氧量**：溶氧 >5mg/L 时对摄食影响小；低于 3mg/L 鱼浮头停口。流动水、风浪天、涨潮期溶氧高（潮水搅动可使近岸溶氧提升 30–50%）；闷热低压、水草夜间耗氧的清晨是低氧高危时段。

**透明度/浊度**：理想垂钓透明度约 30–35 厘米；淡绿、黄褐、青黄色水为"肥水好钓"；过清（人影惊鱼）过浊（缺氧、鱼不适）都不利。

**水草**：水草区是鱼的藏身处、食堂和产卵场，春钓草洞、夏钓草荫是经典战术；水草过度繁殖夜间耗氧，清晨草区反而缺氧。

**上海感潮河段的潮汐影响（本调研要点）**：黄浦江全线、苏州河下游、长江口均为半日潮感潮河段，**每日两涨两落**，周期约 12 小时 25 分。已核实的黄浦公园站典型节奏：涨潮 0:00–03:52 → 落潮 03:52–11:33 → 再涨潮 11:33–16:09。吴淞口附近潮差约 2.9 米（低潮 -0.75 米至高潮 2.15 米，[上海潮汐查询](https://www.zhichaoo.cn/tide/shanghai)）。**涨潮阶段总体好钓**：潮水顶托淡水、水流活跃、溶氧升高、鱼随潮靠岸觅食；**落潮中后段次之**；**平潮前后约 1 小时最难钓**；**转流期是黄金窗口**。苏州河下游因吴淞江闸（河口水闸）调度，潮汐已被人工调控，钓点选择需考虑开闸时段（影响细节待验证）。长江口（长兴、横沙、滨江森林公园一带）潮差更大、咸淡水交汇，涨潮带咸水和饵料鱼进河口，是路亚翘嘴、海鲈的好时机。

## 二、官方免费数据源（逐个核实）

### 1. 上海市水务局（市海洋局）"实时水位"页 — https://swgxh.swj.sh.gov.cn/sw.html
已核实：展示黄浦公园、吴淞口、米市渡三站的实时水位（精确到分钟，如"10-01 21:10:00 黄浦公园 2.02 米"）和预报水位（吴淞口未来高潮时刻）——正是钓友最需要的三个感潮代表站。页面为 Vue 动态渲染，背后是 JSON 接口，需抓包获取（无公开文档）。另有[实时雨量页](https://swgxh.swj.sh.gov.cn/SwjPc/SwjPc/ssyl.html)。**更新频率约每 10 分钟–每小时**。数据后台为上海市水文总站（2024 年全市国家基本水文测站 64 处：水文站 12、水位站 41、雨量站 11，见[市水务局公布](https://swj.sh.gov.cn/shsdfssglc-zwss/20250123/b95f47053e2944168ed36127ab03b00c.html)）。配套公众号：上海防汛、上海水务海洋。

### 2. 水利部全国水雨情信息网 — http://xxfb.mwr.cn/index.html
已核实栏目：洪旱告警、水情查询（地图查询/大江大河/大型水库/重点雨情）。提供河道站水位、流量，水库站库水位、蓄水量，整点更新。注意：黄浦江/淀山湖站点是否纳入"大江大河"列表**待验证**；页面标注"版权所有，未经书面授权禁止使用"，爬取有合规风险。

### 3. 长江水文网（长江委水文局）— http://www.cjh.com.cn/swyb_sssq.html
提供长江干支流及长江口区域实时水情，徐六泾（长江口潮流量代表站）、天生港、杨林等站有实时潮位及过程线（页面动态加载，站级粒度待验证）。适合钓长江口（宝山、浦东沿江）参考。

### 4. 太湖流域水文信息服务（太湖流域管理局水文局）— http://info.tbasw.cn/?Menu=0
已核实站点存在，栏目含实时水情、实时雨情、水量信息、水文预报、太湖风场、卫星云图等。可覆盖太浦闸、淀山湖周边（淀山湖水位代表站为千灯浦、商榻、淀浦河西闸，据[文献](http://slsdkb.xml-journal.net/cn/article/Y2023/I6/76)）。页面 JS 渲染，具体站点清单和更新频率待验证。适合青浦淀山湖、太浦河钓场。

### 5. 上海海事局"潮汐查询" — https://www.sh.msa.gov.cn/shhsfb/information-aim-navigation/tide-search
已核实：免费公开、无需登录，按日提供验潮站高潮潮时+潮高（cm）及**逐小时潮高表**（例：吴淞 2026-10-02，03:18/337cm、10:50/128cm、15:47/390cm），站点通过选择器切换（除吴淞外是否含中浚、外高桥等长江口站待验证）。**目前最权威、结构最规整的上海潮汐表来源，潮汐预报类功能的首选底层数据。**

### 6. 上海市海洋监测预报中心 — [海洋预报专栏](https://swj.sh.gov.cn/shshyhjjcybzx-hyyb/index.html)
每日发布上海海洋预报（长江口内、杭州湾北、洋山港、长江口外海域的风、浪、海温），每周发布下周海况（表层海温趋势等）；台风期发布风暴潮、海浪预警。预警汇总见[上海天气发布](http://wx.soweather.com/wxapp/warn.jsp)（含水文总站黄浦江高潮位预警）。海温数据对长江口海钓季节判断有参考价值。

### 7. 上海市公共数据开放平台 — https://data.sh.gov.cn
平台现有 11058 个数据集、5946 个数据接口，设生态环境数据专区和气象数据专区。已核实存在"**数据上链-水环境监测数据**"（无条件开放、提供数据接口，含环境质量指数、水质等级等字段，调用超万次）；水位/潮位类数据集需登录站内以"水位""水文"检索，是否存在可批量下载的实时水位接口**待验证**。平台接口需注册开发者账号申请，是正规化接入的优先通道。

## 三、可编程 API 方案与技术路线

**官方 API 现状**：上海水务局水位页、海事局潮汐页均无公开 API 文档，但均为前端 JSON 渲染，可通过抓包获得内部接口（稳定性无保障，需自担风险）；xxfb.mwr.cn 明确禁止未经授权使用。**"官方 API 直连"目前不可行，正规路线是开放平台申请。**

**第三方聚合 API（已核实可用）**：
- **和风天气潮汐 API**：https://dev.qweather.com/docs/api/ocean/tide — `GET /v7/ocean/tide`，全球主要港口/城市未来 10 天满潮干潮时间与高度 + 逐小时潮位。国内访问快、文档全，个人免费额度约 400 次/小时（待验证）。**首选。**
- **Stormglass**：https://stormglass.io/global-tide-api — 全球潮位+高低潮时间戳+潮汐站元数据，免费层约 50 次/天（待验证），备选。
- **月萌数据**：https://www.moonapi.com — 整合水利部全国水雨情（3200+ 水文站、600+ 大型水库站），站点坐标数据 100 元/份起，实时接口按站计价需询价。国内水文站数据商业获取的现实选项。
- **NOAA 类世界潮汐开放数据**：NOAA 潮汐站网仅覆盖美国及其属地，中国境内无站点，不可用；国际免费站点（tide-forecast.com、windfinder.com）有上海潮汐但非官方、粒度粗。

**技术路线建议**：
1. 潮汐预报：直接对接和风天气潮汐 API（覆盖吴淞/上海），或爬取海事局潮汐表做本地数据库（一年潮汐表变化极小，可缓存）；
2. 实时水位/潮位：抓包 swgxh.swj.sh.gov.cn 内部 JSON 接口做轮询（10–60 分钟一次，注意缓存与反爬）；
3. 同步走 data.sh.gov.cn 申请水环境监测接口作为合规兜底；
4. 水质周报类低频数据直接定时解析官方网页即可。

## 四、水质数据

上海市生态环境局官网"信息公开→水环境质量"栏目**按月发布**全市地表水水质状况（例：[2026 年 1–6 月全市优Ⅲ类断面占 98.9%](https://sthj.sh.gov.cn/hbzhywpt1143/hbzhywpt1149/20260727/f564f94a9a0048b8a7aaefc2191d8da4.html)），含各断面类别（长江浏河、陈行水库等为Ⅱ类）。区级更细：青浦区政府发布淀山湖断面数据（急水港桥Ⅳ类、四号航标Ⅲ类，见[青浦发布](https://www.shqp.gov.cn/env/shjzk/20240919/1210876.html)）。太浦河近年稳定Ⅱ类（[长三角示范区白皮书](https://view.inews.qq.com/a/20260606A03SUP00)）。

**对选钓点的意义**：Ⅱ–Ⅲ类水鱼活性与食用安全性较好；Ⅳ类及以下水体溶氧波动大、异味风险高。淀山湖虽整体达标但存在蓝藻风险（夏季"初肥水"），钓点宜选湖区东南侧进水口；太浦河水质优良但为供水通道，注意禁钓区。官方数据为月/周级，对单次出钓参考有限，更适合做"钓点水质档案"长期标签。

## 五、垂钓圈常用看水方式与 App

**肉眼看水**：一看水色——淡黄、淡绿、黄褐色为好水，过清过浊不宜（"水至清则无鱼"，[经验帖](https://www.sohu.com/a/627608043_121607353)）；二看鱼花鱼星——水面细密鱼星说明底层鱼觅食，翘嘴炸水说明掠食鱼追饵；三看浮头——清晨鱼浮头=缺氧必停口（[钓鱼人](https://m.diaoyur.com/a/2013/2972.html)）；四看水草和潮水——黄浦江边看驳岸水痕判断潮位涨落。

**常用潮汐工具（已核实存在）**：App 类有全球潮汐表（国内港口可离线）、全球潮汐 Pro、潮汐附近（Tides Near Me，[App Store](https://apps.apple.com/cn/app/id957143504)）、海浪潮汐表（带钓鱼助手）；微信小程序有"查潮汐""渔获"等；网站类有[潮汐表网](https://www.chaoxibiao.net/tides/30.html)（黄浦公园站）、[海潮表](https://haichaobiao.com/cn/shanghai/shanghai-huangpu-river)（黄浦江实时潮汐+日出日落）、潮汐精灵 eisk.cn 等，均可查黄浦江/吴淞，长江口站点覆盖不一。这些站点证明"潮汐+钓鱼"需求真实存在，但都没有接入官方实时水位——**这是上海本地 App 的机会点**。

## 六、结论：水文模块数据接入优先级清单

| 优先级 | 数据 | 来源 | 难度 |
| --- | --- | --- | --- |
| P0 | 黄浦江/吴淞口潮汐表与潮位预报 | 海事局潮汐查询页抓取入库；或和风潮汐 API | 低，结构规整、变化慢 |
| P0 | 实时水位（黄浦公园/吴淞口/米市渡） | 上海水务局内部 JSON 接口轮询；合规兜底走 data.sh.gov.cn 申请 | 中，需抓包+反爬应对 |
| P1 | 转流/平潮时刻提醒、钓期建议 | 基于 P0 潮汐数据自行计算 | 低，纯算法 |
| P1 | 水温/海温/风浪 | 每日海洋预报 + 天气 API 推算淡水水温 | 中 |
| P2 | 水质档案（淀山湖/太浦河断面） | 生态环境局月报 + 开放平台"水环境监测数据"接口 | 低–中 |
| P2 | 淀山湖/太浦闸水位 | info.tbasw.cn 实时水情（站级细节待验证） | 中 |
| P3 | 长江口潮位、上游来水 | 长江水文网；xxfb.mwr.cn（注意版权限制） | 中–高 |

**总体判断**：上海钓鱼 App 水文模块的**核心资产是潮汐**——官方数据齐全且免费可得，技术上是"爬取+缓存+API 兜底"的组合，真正的壁垒在于把潮汐数据转化为"转流窗口提醒""钓点潮汐适配度"等钓鱼语义功能。
