# fisherman · 上海钓鱼综合应用

面向上海及周边水系的钓鱼助手项目。服务对象：上海纯新手钓友（作者本人），逐步扩展到钓点、水情、天气、装备、硬件（水下鱼情检测器）五个方向。

## 应用现状（V3 · 已可运行）

六个功能页：**出钓指数 · 潮汐水文 · 钓点地图 · 钓鱼日志 · 装备清单 · 合规速查**。

### V1（MVP）
1. **出钓指数**：Open-Meteo 逐小时数据 + 100 分制透明评分（气压趋势 25 / 气压绝对值 20 / 风 20 / 季节时段 15 / 降水 10 / 温差湿度 10；6 级大风、7 级阵风、≥8mm/h 强降雨一票否决）。输出当前分数、未来 48h 最佳窗口、逐小时图表和"为什么要扣分"的解释。规则实现在 `server/scoring.py`，阈值全部集中在常量区，便于用渔获日志回填校准。
2. **钓点地图**：Leaflet + OpenStreetMap，47 个调研钓点按类型着色（官方垂钓点/河道野钓/收费钓场/禁钓警示），按区筛选，附鱼种、费用、合规要点、来源链接与置信度标签。含张家浜沿线 9 个点位专题、苏州河普陀 7 处官方点位明细。
3. **合规速查卡**：一人一杆一线一钩、禁渔期、禁钓区、饵料与设备红线，每条带官方原文链接。

### V2（2026-10-02）
4. **潮汐水文**：上海海事局潮汐查询页抓取（21 站，服务端渲染直读）+ 市水务局实时水位/预报潮位 JSON 接口。把潮汐表转成钓鱼语义：**当前阶段**（涨潮/落潮/平潮/转流初期）、**转流黄金窗口提醒**、48h 潮汐曲线+阶段带、高低潮时刻表。规则见 `server/tide.py`（平潮=高低潮前 40 分钟~后 30 分钟，转流初期=平潮后 2.5 小时）。
5. **感潮点位联动**：钓点库新增 `tidal` 标记（7 个感潮点位）；在出钓指数页选择感潮钓点时自动显示当前潮相与下次转流窗口。
6. **钓鱼日志**：SQLite 存储，记录日期/钓点/时段/天气快照（一键填入当前评分与天气）/渔获/饵料/满意度/备注，自动统计出钓次数、累计渔获、鱼种分布、口碑钓点排行——为日后回填校准出钓指数权重积累数据。
7. **装备清单**：15 件购物清单（勾选进度存本机 localStorage）+ 三档预算方案 + 老三样季节配比与开饵四步。

### V3（2026-10-02）
8. **预警横幅**：聚合上海市预警发布中心（`wx.soweather.com/wxapp/jsondata/warn.js`，含生效中预警）与市水务局防汛预警信号，页面顶部全局横幅展示；命中暴雨/台风/雷电/大风关键词时追加"建议今日不出钓"的红色安全提示。规则见 `server/alerts.py`。
9. **水质钓点档案**：按水体收录有官方来源的水质等级（太浦河Ⅱ类、淀山湖Ⅲ~Ⅳ类分断面、长江口Ⅱ类、全市优Ⅲ类 98.9% 背景），显示在钓点详情/弹窗，带月报来源与数据时点；无来源的水体不硬编。见 `server/data.py` 的 `WATER_PROFILES`。
10. **夜钓月相**：本地天文近似算法（平均朔望月）计算月相与照亮比例，出钓指数页显示"今晚月相"与夜钓建议（新月前后好钓、满月前后鱼警觉）。
11. **出钓指数校准**：日志页新增"预测 vs 实际"分桶分析——按评分桶（<35/35-54/55-74/≥75）对比实际满意度，满 10 条样本后给出校准提示，作为评分权重自学习的数据通路。

### 运行

```bash
./run.sh                 # 首次会自动创建 .venv 并装依赖，然后启动
# 打开 http://127.0.0.1:8787
```

手动方式：`python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt && uvicorn server.main:app --port 8787`（需在项目根目录运行）。

### 部署（Vercel）

已含 serverless 适配（`api/index.py` 入口 + `vercel.json`）。方式二选一：

```bash
vercel --prod            # CLI 部署（需 vercel login）
```

或在 [vercel.com/new](https://vercel.com/new) 导入 `CrazyRock114/shfisher` 仓库，其余零配置。

**Vercel 上的已知差异**：应用目录只读，钓鱼日志库自动落到 `/tmp`——实例回收后日志即丢失（日志在 serverless 上是"会话级"功能）；潮汐/水位/预警缓存同理。长期数据以本地部署为准。

### 接口

| 端点 | 说明 |
| --- | --- |
| `GET /api/score?lat=&lon=&label=` | 出钓指数（未来 48h 逐小时评分 + 最佳窗口 + 按日汇总），10 分钟缓存 |
| `GET /api/spots` | 钓点库（含坐标、鱼种、费用、合规、来源、置信度、tidal 感潮标记） |
| `GET /api/compliance` | 合规速查条目 |
| `GET /api/tide?station=吴淞` | 潮汐表 + 钓况阶段 + 转流窗口（21 站可选，6 小时缓存） |
| `GET /api/waterlevel` | 市水务局三站实时水位 + 预报潮位（10 分钟缓存） |
| `GET /api/alerts` | 上海市预警发布中心 + 水务局防汛预警聚合（5 分钟缓存） |
| `GET /api/waterquality` | 水质钓点档案（有官方来源的水体等级） |
| `GET/POST/DELETE /api/log` | 钓鱼日志（SQLite，`data/fisherman.db`，含校准分桶统计） |

### 结构

```
server/
  main.py      # FastAPI：score/spots/compliance/tide/waterlevel/alerts/waterquality/log + 静态页
  scoring.py   # 出钓指数评分引擎（纯函数，阈值常量集中，可单测）
  tide.py      # 潮汐抓取解析（海事局 HTML）+ 阶段/转流算法 + 水务局水位
  alerts.py    # 预警聚合（市预警发布中心 warn.js + 水务局防汛信号）
  log_db.py    # 钓鱼日志 SQLite（含校准分桶统计）
  data.py      # 钓点加载 + 合规条目 + 水质档案
web/           # 零构建前端（原生 JS + Chart.js + Leaflet CDN）；改 JS/CSS 后请递增 index.html 里的 ?v= 版本号
tests/         # 评分/潮汐/日志/预警/水质单元测试：.venv/bin/python -m pytest tests/ -q
data/          # fishing_spots.json 钓点数据 + fisherman.db 日志库（不入 git）
```

注：天气源 api.open-meteo.com、潮汐源 sh.msa.gov.cn、水位源 swgxh.swj.sh.gov.cn 均需联网，失败时页面会明确提示；官方页面若改版，`server/tide.py` 的解析正则需同步调整（有真实页面夹具测试兜底）。前端 CDN（Chart.js/Leaflet）首次加载需联网。

## 项目目标

1. **钓得明白**：知道去哪钓、能不能钓、今天值不值得出钓。（V1 已覆盖）
2. **钓得合规**：内置上海垂钓法规红线（一人一杆一线一钩、禁渔期、禁钓区），不踩雷。（V1 已覆盖）
3. **钓得省心**：装备饵料少花钱少走弯路，出钓清单一键生成。（V2 已覆盖）
4. **钓得科学**：接入潮汐/水位/天气数据，用可解释的算法给出出钓建议，而非黑盒指数。（V1 天气 + V2 潮汐已上线）
5. **玩得硬核**：第二年起自研水下鱼情检测器（声呐 → 水下摄像头 → 微型 ROV → 传感器组网）。（硬件线，见 docs/05）

## 快速结论（给 30 秒的读者）

- **合规底线**：全年娱乐垂钓合法且无需办证，但必须一人一杆一线一钩；长江口两片保护区、水源一级保护区、崇明 4 处区域禁钓；每年 2.16–5.16 为内陆禁渔期；**可视探鱼设备在长江口禁捕管理区明文禁止，水下摄像头/ROV 在自然水域使用有灰色风险**。
- **新手第一年路线**：收费塘练手感 → 苏州河/白莲泾官方垂钓点 → 川杨河、大治河等河道野钓 → 淀山湖水系河荡。淀山湖本体有水源保护区禁钓岸线，新手避开。
- **App 最有价值的第一件事**：可解释的"出钓指数"（气压趋势 + 风力 + 降水 + 季节时段）+ 黄浦江**转流窗口提醒**（上海是感潮河网，潮汐比天气更本地化）。
- **硬件第一件事**：先花 250–450 元买国产无线声呐验证需求，浑水中声呐是主力、摄像头是配角；DIY ROV 放到第二年。
